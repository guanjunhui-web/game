# 照片放置说明

后续把照片放到这个文件夹，并按下面名字保存。游戏会继续使用占位画面，直到我们把照片接入最终页面。

## 必须

- `parents-final.jpg`：你和太太的清晰合照，用于最终揭晓。

## 推荐

- `dad.jpg`：爸爸单人或生活照。
- `mom.jpg`：妈妈单人或生活照。
- `home-corner.jpg`：家里温馨角落，比如灯、沙发、餐桌、小床。
- `family-final.jpg`：全家福，用于生日结尾彩蛋。
- `daughter-reference.jpg`：女儿清晰正面照，用于之后把小天使画得更像她。

## 拍照建议

- 光线自然，脸清楚。
- 不要强滤镜。
- 最终合照最好是温暖、自然、正面的照片。
- 如果不想暴露女儿照片，可以只提供父母合照，小天使继续使用现在的圆脸短发设定。
